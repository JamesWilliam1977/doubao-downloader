# 设置页 Tabs 重构设计

## 目标

将当前纵向堆叠的设置项整理为可扫描的分类 tabs，降低一次性认知负担，同时保留现有设置键、默认值、Dexie 持久化和实时更新行为。

## 信息架构

- **下载行为**：对话列表显示无水印原图、跳过已下载的图片、按展示顺序下载、下载图片并发数。
- **文件与目录**：自定义图片文件名、为会话创建文件夹。
- **视频**：开启 15 秒视频。
- **关于**：展示应用版本和简短说明；该 tab 为只读，不引入新的持久化设置。

## 交互与布局

- 使用 Semi UI 的 `Tabs`/`TabPane`（或项目当前版本对应的 tabs API），设置弹窗标题继续为“设置”，关闭行为继续 flush 两个防抖输入。
- 桌面宽度采用左侧窄导航、右侧内容区；当前 tab 有明确的品牌绿色强调线/背景。
- 设置项以全宽行呈现：左侧为标签和辅助说明，右侧为开关、数字输入或文本输入；行之间使用细分隔线，避免标签与控件挤在同一行。
- 输入控件统一宽度，文件名模板允许单行横向滚动或省略，保留完整编辑能力和原占位提示。
- 小屏幕下 tabs 变为顶部横向滚动，内容区保持单列，控件在窄屏不溢出。
- 进入弹窗时默认选中“下载行为”；切换 tab 不重置或延迟提交任何设置。

## 视觉方向

采用“克制的工具面板”方向：浅灰背景、白色内容面、深灰文字、绿色作为唯一主强调色，辅以圆角 8px、细边框和轻微阴影。标题、tab 标签和设置项标签建立清晰的字号层级，不使用装饰性渐变或大面积卡片。

## 组件边界

- `SettingModal` 负责 tab 编排、设置项分组和弹窗生命周期。
- 新增本地 `SettingRow` 展示辅助组件，统一标签/说明/控件对齐，不承载业务状态。
- 通过现有 `getSetting`、`changeSetting` 和 `useSetting` 更新数据，避免复制设置逻辑。
- 样式优先使用现有 Tailwind 前缀类；仅在 `src/index.css` 添加必要的 Semi UI 覆盖和响应式规则。

## 验证

- `pnpm build` 必须通过 TypeScript 与 Vite 构建。
- 手动检查：四个 tab 均可切换；开关立即持久化；文本和并发数输入在关闭弹窗时 flush；窄屏下无横向溢出；关闭按钮仍可用。
